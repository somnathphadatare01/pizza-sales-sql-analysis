# pizza-sales-sql-analysis
SQL-based analysis of pizza sales data to uncover revenue trends, customer behavior, and top-performing products using advanced queries.


This project analyzes a pizza sales dataset using SQL to extract meaningful business insights such as revenue trends, customer behavior, and product performance.

The project covers **basic to advanced SQL queries**, including joins, aggregations, window functions, and views.

---

## 🎯 Objectives

* Analyze total orders and revenue
* Identify best-selling pizzas
* Understand customer ordering patterns
* Evaluate category-wise performance
* Track revenue trends over time

---

## 🗂️ Database Used

* Database Name: `pizza_project`
* Tables:

  * `orders`
  * `order_details`
  * `pizzas`
  * `pizza_types`

---

## 🛠️ Tools & Technologies

* SQL (MySQL)
* DBMS

---

## 🔍 Key Analysis Performed

### 🔹 Basic Analysis

* Total number of orders
* Total revenue generated
* Highest-priced pizza
* Most common pizza size
* Top 5 most ordered pizzas

### 🔹 Intermediate Analysis

* Category-wise pizza sales
* Hourly order distribution
* Average pizzas ordered per day
* Top pizzas by revenue

### 🔹 Advanced Analysis

* Revenue contribution (%) by each pizza
* Cumulative revenue over time
* Top pizzas within each category using ranking

---

## 📈 Key Insights

* 🍕 Highest revenue-generating pizzas identified
* 🕒 Peak ordering hours discovered
* 📊 Certain categories dominate total sales
* 💰 Revenue contribution varies significantly across pizza types

---

## 🧠 SQL Concepts Used

* Joins (INNER JOIN)
* Aggregations (SUM, AVG, COUNT)
* Subqueries
* Views
* Window Functions (RANK, OVER)
* Group By & Order By

1. Create database:

   ```sql

   ```
